# Light-Knight

2D Coin Collector is a simple game where you move around, collect coins, and avoid enemies. Built using Godot.

Features:

Collect coins to increase your score

Simple 2D movement system

Avoid enemies or lose the game

Basic collision and gameplay mechanics

Lightweight and easy to run

Gameplay:

Move around the map and collect as many coins as possible

Avoid touching enemies

Try to get the highest score before getting caught

Controls:

WASD or Arrow Keys to move

Requirements:

Godot Engine (version 3.x or 4.x)


Future Improvements:

Add sound effects and music

Add more levels

Improve enemy behavior

Add UI (menu, restart button, score display)

Notes:

This is a beginner-friendly project made for learning Godot basics.
